# Superpowers ドキュメント運用方針

このディレクトリ（`docs/superpowers/`）には、AI エージェントが自動生成・管理する設計書（Specs）および実装プラン（Plans）が格納されています。

## ディレクトリ構造

- `specs/`: 機能ごとの詳細設計書。UIコンポーネントの仕様や共通ルールの定義を含みます。
- `plans/`: 特定のタスクを完遂するためのステップバイステップの実装プラン。進捗管理（チェックリスト）に使用されます。

## 運用ルール

1.  **Git 管理**: このディレクトリ配下のドキュメントは、プロジェクトの歴史と意図を記録するため、**常に git 管理対象**とします。`.gitignore` で除外されている `.superpowers/` ディレクトリ（内部状態管理用）とは異なります。
2.  **最新性の維持**: 実装時に設計の変更や追加が発生した場合は、実装完了までに必ず対応する Spec および Plan を更新してください。
3.  **完了定義**: Plan 内のすべてのチェックボックスが埋まり、関連する Spec と実装の整合性が取れている状態をもってタスク完了とみなします。
