Accordion — collapsible Q&A or detail rows. Stack several for an FAQ.

```jsx
<Accordion title="申請に必要な書類は？" defaultOpen>
  本人確認書類と申請書をご用意ください。
</Accordion>
<Accordion title="手数料はかかりますか？">無料です。</Accordion>
```

- Built on `<details>` — keyboard and no-JS friendly. The circular chevron rotates on open.
